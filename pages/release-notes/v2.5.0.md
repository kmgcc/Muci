## [v2.5.0] - 2026-11-20

### Added

- 自定义皮肤新增 GPU 图层渲染，封面、文字、描边、光环与彗星改由 Metal 绘制。
- 皮肤支持 JavaScript 脚本，可自行编排舞台与镜头运动。
- 新增「字潮」皮肤，含对唱、GPU 背景与歌词舞台效果。

### Improved

- 播放器更名为 Muci。升级后继续使用原有资料库与设置，新建默认资料库使用 Muci Library。

- 播放界面新增进度条、操作栈与播放模式栈组件，队列面板改由场景宿主渲染。
- NCM 转换日志在每次来源扫描中只读取一次。

### Fixed

- 修复移除资料库根目录时的处理问题。

### Files

DMG 为安装包；`.symbols.zip` 用于崩溃报告符号化，日常使用无需下载；`.sha256` 为安装包和符号包的校验文件。
